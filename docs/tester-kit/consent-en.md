# Consent form (English)

> The same text appears inside the game on the consent screen (tester mode, English UI). This copy is for anyone who wants a written record, and for a parent/guardian when needed.

## Consent to take part in testing "Real or Ruse?"

**What is it?** An educational web game that trains people to spot scam messages by investigating, not guessing. It is being developed as a Technovation Girls 2026–2027 project.

**What will I do?** Answer 6 short messages before playing, play 4 investigation cases, answer 6 messages after playing, then 8 feedback questions. About 20 minutes.

**What data is collected?**
- Only my in-game answers (verdict, confidence, choices, timing, and feedback answers).
- An anonymous tester code (e.g. T-0427) instead of a name. Age is optional and only as a band (13–15 / 16–18 / 19+).
- **No** name, phone number, email, or any personal identifier. No tracking tools and no server. Everything stays on my device until I choose to copy the "results code" and send it myself.

**How is it used?** To improve the game and to report aggregated numbers in the competition materials. No tester is ever identified.

**My rights:** Taking part is voluntary. I can stop at any time and I can choose not to send the results code. All names and companies in the game are fictional and no real link ever opens.
