# بروتوكول جلسات الاختبار مع المختبرين

> الهدف (build-plan §8، §11): ثلاث جولات، كل جولة لها عدد مستهدف وملاحظات مسجّلة وتغييرات محددة نتجت عنها. rubric Technovation يطلب **تكرارين موثَّقين على الأقل** بأمثلة تحسين من الملاحظات (`docs/research-technovation.md`).

## قبل كل جولة
1. `npm run build` + E2E على النسخة المبنية (`BUILD-LOG.md` يسجّل النتيجة).
2. انشري النسخة (`DEPLOY.md`) واختبري الرابط من جوال حقيقي.
3. ولّدي أكواد المختبرين (T-0101…) وسجّليها في ملف خاص عندك فقط.
4. أرسلي `docs/tester-kit/message-ar.md` مع الرابط والكود.
5. احفظي لقطات شاشة «قبل» للشاشات التي تتوقعين تغييرها.

## أثناء الجلسة (إن جلستِ مع المختبِر)
استخدمي `docs/tester-kit/observation-sheet.md`. لا تساعدي إلا عند التوقف التام.

## بعد الجولة
1. اجمعي رموز النتائج في `analysis/data/round-N/codes.txt` (رمز في كل سطر) أو ملفات JSON في نفس المجلد. **هذا المجلد لا يُرفع إلى GitHub** (أضيفيه إلى `.gitignore` قبل أول بيانات حقيقية).
2. شغّلي:
   ```
   cd analysis
   python analyze.py --input data/round-N --out output/round-N
   ```
3. اقرئي `output/round-N/summary.md` والرسوم.
4. املئي جدول الجولة أدناه بصدق: إن لم يظهر تحسن، اكتبي ذلك.
5. حوّلي الملاحظات إلى قائمة تغييرات محددة (ملف/شاشة/نص) ونفّذيها في جلسة تعديل قصيرة.
6. احفظي لقطات «بعد».
